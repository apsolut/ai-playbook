# What to buy

Spend money where it removes risk or hours — not where a logo feels modern. Prices change. Every page here points at the vendor’s own price list instead of copying it.

<LevelBadge level="starter" /> One coding-agent seat, one EU model path, one EU server. Then stop shopping.

## Starter

<LevelBadge level="starter" />

| Need | Buy | Do not buy yet |
|------|-----|----------------|
| A place to write code with an agent | One seat: Cursor, Claude, Codex, or Grok. See [tools](/what-to-buy/tools-and-plans) and [coding agents](/work-with-ai/coding-agents) | Four seats so you can “compare” on a client repo |
| A model for **client** personal data | An API with a DPA and an EU deployment you selected | A consumer chat subscription plus copy-paste |
| A machine for you | The laptop you already develop on | A GPU “for AI” when the model runs in the cloud |
| A place for n8n or a small service | One EU VPS ([hosting](/run-agents/hosting)) | A second cloud because the panel is prettier |

## Everyday

<LevelBadge level="everyday" />

- Seats are for **you** building. APIs are for **production**. Mixing them is the usual way client data lands in a consumer training setting. Read [API vs consumer plans](/what-to-buy/api-vs-consumer).
- Hardware stays boring until you have a reason to keep prompts on a machine you own. [Hardware](/what-to-buy/hardware).
- Add backups and a budget alert before you add another SaaS. [Costs](/run-agents/costs).

## Advanced

<LevelBadge level="advanced" />

- Separate staging and production keys. The staging key can have a low cap.
- SSO on n8n or the host only when a second operator exists. SSO for one person is optional.
- A log vendor is a new processor. Prefer logs on the EU VM until you have a DPA and a retention setting.

## Complex

<LevelBadge level="complex" />

- Local inference is a **data-location** choice, not a hobby. You then patch the runtime, license the weights, and size the GPU from the model card. Do not guess from a forum.
- Multi-client hosting is more machines or hard isolation, not a bigger consumer plan. [Hosting](/run-agents/hosting).
- If a procurement form asks for a model price, paste the date and the link to the official page. Do not paste a number from this site. There isn’t one.
