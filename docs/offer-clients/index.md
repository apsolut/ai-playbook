# Offer clients

Package what you sell so scoping stays boring (in a good way). A short menu beats a custom “AI employee” for every lead.

<LevelBadge level="starter" /> Sell one of the three standard agents before you invent a fourth.

## The menu

| Piece | Page |
|-------|------|
| What the agent does and refuses | [Three standard agents](/offer-clients/three-standard-agents) |
| What you charge, roughly, and what is inside | [Tiers & pricing](/offer-clients/tiers) |
| How you learn enough to write the scope | [Discovery & scoping](/offer-clients/discovery) |
| How you hand it over | [Delivery checklist](/offer-clients/delivery-checklist) |

The money figures on the tiers page are **orientation** for a conversation (Starter about €2,900, Pro about €5–7k, Care about €300–600 per month). They are not a quote, not a market study, and not VAT advice.

## Starter

<LevelBadge level="starter" />

- One agent from the menu. Website support **or** lead booker **or** inbox drafts.
- Fixed list of systems (one site, one calendar, one mailbox).
- Draft-only where a message could reach a customer.
- You can explain the out-of-scope list in one minute.

## Everyday

<LevelBadge level="everyday" />

- Put the work in a tier so “small change” has a meaning.
- Discovery notes name data types (contacts, ticket text) without pasting a real export into your notes app.
- The client knows who is controller and that an AVV is part of starting, not a surprise at the end. [Legal overview](/legal/).

## Advanced

<LevelBadge level="advanced" />

- SLA language is only what you can keep: a human reply window, a disable switch, a monthly review. Not “99.9%” unless you have measured it and the host agrees.
- Integrations are a list with owners. An unowned CRM field is not in scope.
- Eval set exists before go-live. [Evals](/run-agents/evals-monitoring).

## Complex

<LevelBadge level="complex" />

- Multi-brand or multi-locale is a Pro conversation, not a verbal yes on a Starter.
- Hiring, performance scoring, credit decisions, and other Annex III uses are a no. See the [compliance checklist](/legal/germany-eu-compliance).
- Several clients never share one n8n and one API key. [Hosting](/run-agents/hosting).
