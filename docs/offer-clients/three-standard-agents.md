# Three standard agents

<LevelBadge level="everyday" /> Sell a short menu. Custom everything is how projects never end.

::: tip Pricing pointer
Ballpark tiers (Starter ~€2,900 · Pro ~€5–7k · Care ~€300–600/month) live on [Tiers & pricing](/offer-clients/tiers). Adjust for scope — these are orientation figures, not a quote.
:::

## 1 · Website & support agent

**Job:** Answer FAQs, route to humans, never invent policy.

| In scope | Out of scope |
|----------|--------------|
| Public FAQ / help-center grounded answers | Legal advice, medical advice |
| Handoff to form / email / live chat | Autonomous refunds without rules |
| Locale the site already uses | Training on raw customer tickets with no AVV |

**Starter depth:** scripted intents + retrieval over approved pages.  
**Everyday:** ticket creation with fields validated.  
**Advanced:** authenticated account snippets via APIs the client already has.  
**Complex:** multi-brand knowledge with hard separation.

## 2 · Lead qualifier & booker

**Job:** Ask qualifying questions, book a slot, write to CRM.

| In scope | Out of scope |
|----------|--------------|
| BANT-like or client-defined qualifiers | Credit scoring, automated rejection with legal effect |
| Calendar booking via official API | Scraping personal data from the open web |
| CRM note with source + transcript link | Annex III hiring / recruitment decisions |

Disclose AI on the widget ([compliance checklist](/legal/germany-eu-compliance)). Keep a human confirm path for high-value meetings if the client wants it.

## 3 · Back-office inbox agent

**Job:** Triage shared inbox, draft replies, label, escalate.

| In scope | Out of scope |
|----------|--------------|
| Label + summarize + draft | Silent send on day one |
| Extract structured fields to sheets/CRM | Long-term archive of all mail in the LLM vendor |
| Escalation rules by sender / keyword | HR performance decisions from mailbox content |

**Send policy:** draft-only until Care-tier monitoring says otherwise, then allowlist templates.

## Shared delivery checklist

The long form, with handover notes, is the [delivery checklist](/offer-clients/delivery-checklist). Minimum before production:

- [ ] EU LLM path + DPAs ([legal](/legal/germany-eu-compliance))
- [ ] Art. 50 disclosure on any public chat surface
- [ ] Retention set for transcripts ([retention defaults](/legal/retention))
- [ ] Eval set of 20–50 real questions, redacted ([evals](/run-agents/evals-monitoring))
- [ ] Kill switch / disable flag documented for the client
- [ ] Scope written down ([discovery](/offer-clients/discovery)) so a new channel is a change, not a surprise

## What not to invent as a “fourth standard”

Avoid marketing “AI employee that runs the company.” Keep the menu to these three until you have repeatable playbooks and counsel for anything riskier.
